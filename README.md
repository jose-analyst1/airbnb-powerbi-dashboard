# 🏡 Gestión Inteligente de un Airbnb mediante Power BI

## Descripción

Proyecto de Business Intelligence desarrollado con Power BI utilizando datos reales de reservas de un alojamiento turístico gestionado mediante Airbnb.

El objetivo es analizar el comportamiento de las reservas, optimizar la estrategia de precios y facilitar la toma de decisiones mediante un dashboard interactivo.

---

## Herramientas utilizadas

- Microsoft Excel
- Power BI
- DAX

---

## Dataset

El análisis incluye:

- 45 reservas reales
- Julio 2025 – Agosto 2026
- Precio por noche
- Ingreso neto
- Comisión Airbnb
- Número de huéspedes
- Noches reservadas
- Temporada
- Año
- Trimestre

---

## Funcionalidades

- Dashboard ejecutivo
- KPIs principales
- Simulador de incremento de precios
- Recomendaciones estratégicas
- Informe PDF

---

## Principales conclusiones

- La temporada alta concentra la mayor parte de los ingresos.
- Existe margen para incrementar el precio entre un 5 % y un 10 %.
- Las reservas largas generan una mayor rentabilidad.
- La política de estancia mínima de 11 noches reduce costes operativos.
